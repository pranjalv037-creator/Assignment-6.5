Assignment 6.5 — Profile Card Mini-Project

Aim

To create a responsive profile card component using HTML and CSS, applying box model properties, backgrounds, borders, rounded corners, and positioning.

Features

- Profile image with rounded corners.
- Name and professional role.
- Short personal description.
- Skills displayed as labels.
- Contact button.
- Availability badge positioned using "position: absolute".
- Responsive layout for different screen widths.

CSS Properties Used

- "padding", "margin", and "border" for the box model.
- "background" and "border-radius" for styling.
- "position: relative" and "position: absolute" for badge placement.
- "max-width" and a media query for responsive design.
- "display: flex" and "flex-wrap" for arranging skill labels.

Files Included

- "index.html" — Profile card structure.
- "style.css" — Styling and responsive layout.
- "profile-card-screenshot.png" — Screenshot of the completed profile card.
